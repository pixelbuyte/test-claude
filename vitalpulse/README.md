# VitalPulse

An honest pulse, heart-rhythm, and blood-pressure *tracking* app for iOS and
Android — built after researching why people love/hate this app category, so
it fixes the deficiencies instead of repeating them.

- **[`PRODUCT_DESIGN.md`](./PRODUCT_DESIGN.md)** — market research + full
  product/design spec.
- **[`prototype/`](./prototype/index.html)** — clickable HTML mockup of every
  screen (open directly in a browser).
- **[`app/`](./app)** — the real Expo/React Native/TypeScript app for iOS +
  Android. See `app/README.md` to run, test, and publish it.
