Front — Umbra
Reactive-instinct suit · TELLTALE
SENSOR VISOR
Head-mounted array. Wide-field motion + depth read, forward bias.
CUE NODE — PALM
Mirrored, both hands. Haptic pulse fires a beat before predicted contact.
CUE NODE — SOLE
Mirrored, both feet. Cues footing before a stumble or a bad plant.

IMU + proximity fusion. Reads incoming motion, arbitrates which node fires.
LATENCY BUDGET
Sense-to-cue loop targets ~30–50 ms — a heads-up, not a reflex.
THIS AUGMENTS AWARENESS AND DECISION-MAKING — NOT REFLEX SPEED. THE CUE ARRIVES BEFORE THE HAZARD, NOT FASTER THAN THE BODY.
