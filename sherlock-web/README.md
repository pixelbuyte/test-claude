# Sherlock - Free OSINT Username Finder

A free, open-source web tool to find someone's social media accounts and internet presence across 40+ websites.

## Features

✅ **Username Search** - Enter any username and find where accounts exist  
✅ **Multi-Site Check** - Searches across social media, dev platforms, gaming sites, blogs, and more  
✅ **Progressive Results** - Live results appear as the scan progresses (no waiting for everything)  
✅ **Grouped Results** - Found, not-found, and skipped results organized separately  
✅ **Export Options** - Copy as text, JSON, or download a report file  
✅ **Fast & Free** - No API keys, no sign-ups, no cost  

## How It Works

1. Enter a username
2. The tool checks that username across ~45 websites simultaneously
3. Results appear in real-time as each site responds
4. Found profiles are clickable links
5. Export results as text, JSON, or TXT file

## Limitations

- **Rate limiting:** Most sites rate-limit or block automated requests. Some results may be "unknown/timeout"
- **Dynamic content:** Sites that require JavaScript to load may not be detectable
- **Login-required:** Some sites need you to be logged in to view profiles, so detection is less reliable
- **API limits:** Third-party site behavior changes frequently

## FAQ

**Q: Why are some sites showing "timeout" or "unknown"?**  
A: Third-party websites may block or rate-limit the server's requests. This is normal and not a bug.

**Q: Can I search without internet?**  
A: No, the tool needs internet to connect to each website.

**Q: Are my searches logged?**  
A: No. Searches run client-side and server-side without storage or analytics.

**Q: Can I use this for research/journalism?**  
A: Yes, if you have consent and follow legal/ethical guidelines in your jurisdiction.

**Q: Is this a dark web tool?**  
A: No, it only searches public, clearnet websites.
